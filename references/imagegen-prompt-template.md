# 概念插画生成

仅在用户需要或封面/抽象概念确实受益时使用。先按visual-evidence.md选素材，不用生成图补造官网、评论、操作界面和测试结果。

## 调用

优先直接使用当前image_gen工具并遵循其指引；有imagegen技能时读取。不启动嵌套codex exec，不凭订阅或CLI开关判断能力。使用返回的准确文件路径，复制项目资产到文章目录并保留原件。多图按请求与返回对应，不猜“最新文件”。

失败记录原因，有限尝试受支持的替代途径；无法取得就报告缺图，不伪造截图。

## 提示词

说明段落用途、主体、构图与比例。仅为插画应用visual_style_anchor，不改变真实截图。说明是概念图，不含伪造UI、评论或实测数据，避免复制品牌身份。默认不含文字，需要文字时逐字核对。

保留最终提示词、工具返回路径、用途及“AI生成概念图”图注。查看实际图像，检查内容、构图与可读性；不合适可定向修订一次。只有用户需要选择或存在实质不确定性时才提供多个候选，不默认额外生成摄影/插画两套。
