# 概念插画生成

**验证次数：0**——目前真实生图走的都是[工具分工](tools-guide.md)里"当前会话没有生图能力，交给 ChatGPT"这条路径；这份文档描述的"当前会话直接调用 image_gen 工具"这条分支还没有真实用过，不要在没有新证据前继续扩展它。

仅在用户需要或封面/抽象概念确实受益时使用。先按visual-evidence.md选素材，不用生成图补造官网、评论、操作界面和测试结果。

## 调用

优先直接使用当前image_gen工具并遵循其指引；有imagegen技能时读取。不启动嵌套codex exec，不凭订阅或CLI开关判断能力。使用返回的准确文件路径，复制项目资产到文章目录并保留原件。多图按请求与返回对应，不猜“最新文件”。

失败记录原因，有限尝试受支持的替代途径；无法取得就报告缺图，不伪造截图。

## 提示词

正文插画说明段落用途、主体、构图与比例；封面先按[标题与封面](title-and-cover.md)确定文章承诺、产品识别和画面关系，不能只把关键词换成一个物体。visual_style_anchor作为风格参考，不改变真实截图，也不压过主题关联。说明是概念图，不含伪造UI、评论或实测数据。按识别需要决定是否加入产品名与短文案，文字逐字核对；无法可靠生成时再采用留字区与后期排字。

保留最终提示词、工具返回路径、用途及“AI生成概念图”图注。查看实际图像，检查内容、构图与可读性；不合适可定向修订一次。只有用户需要选择或存在实质不确定性时才提供多个候选，不默认额外生成摄影/插画两套。
