# 示例产出

用 wxstyle 写出来的一篇真实文章，展示一次 `wxstyle-write` + `wxstyle-review` 完整跑完之后交付目录长什么样。

[jev-2026-09-21/](jev-2026-09-21/) 是一篇资料介绍类文章（介绍 TypeSafe AI 发布的 Jev 模型），包含：

| 文件 | 对应 [README「一篇文章的产物」](../README.md#一篇文章的产物) |
|---|---|
| `article.md` | 正文，可直接粘贴到公众号后台 |
| `review.md` | 标题候选、摘要、主张与来源表、质量自评、机械检查结果、待办 |
| `sources.md` | 核对过的完整链接和核对日期 |
| `delivery.json` | 交付状态和素材清单 |

**没有带 `images/`**：文中引用的一张图是官方文档页面的截图，版权归原作者，正文末尾也标注了"如需商用请自行确认授权"——这类第三方素材不适合直接放进公开仓库分发，所以只保留文字部分。真实使用时 `images/` 会连同截图和生成的封面一起交付。

这篇文章的机械检查结果（写这份示例时）：`check_layout` 0 error、`ai_tell_check` 0 强命中、`claim_check --review` 0 issue、`similarity_check` 对三个对标画像的最高相似度 0.06%。不代表每次产出都这么干净，是机械检查能做到的上限，不是质量保证。
