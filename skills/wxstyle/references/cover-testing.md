# 封面吸引力：生成假设、分层测试、记录证据

**验证次数：0**——目前没有一篇文章走过这套流程，也没有任何发布数据。下次用到时先看是否还适用，不要在没有新证据前继续扩展它。

用于用户要求提高封面吸引力、比较方案或验证点击效果时。普通单图请求只做设计与可读性检查，不自动扩展成招募读者、批量生图、付费投放或发布实验。没有行为数据，称“候选方案/设计判断”，不称“高点击封面”。

## 从文章生成值得测试的方案

先明确：谁会看到、在哪个入口看到、他能从正文得到什么。封面与标题是同一个阅读承诺；案例不能盖过产品定位，例如Jev讲判断能力，客服分单只是例子，不应让人误认成客服软件。

设计时依次作判断，不当作点击率预测公式：
- 相关：读者能认出与自己的问题或兴趣有什么关系。
- 具体：用可理解的任务、变化、对比或问题，替代“颠覆/强大/高级”。
- 可辨认：一个主要信息焦点，产品或主题有身份线索；在实际显示尺寸可读。
- 有信息缺口：说明读者会获得什么答案，而非故意藏产品名、夸大恐惧或编热度。
- 可信且兑现：画面和文案的承诺能在正文找到；不捏造截图、实测、数字。
- 标题配合：保留必要关键词，画面补充一项信息，不重复铺满整句标题。

先内部比较两三个概念方向：具体收益、真实问题、证据反差等，仅选文章有支撑的方向。默认只生成请求范围内的图。用户需要A/B测试时，通常先用两个候选控制成本。

每个候选写成可否定的假设：“对[读者]，把[原表达]改成[新表达]，可能让更多人[选择打开]，因为[具体理由]；若[误解或数据结果]出现则不支持。”
不是把提示词写得越长越好。保留受众、承诺、逐字文案、核心关系、视觉层级、比例与误读边界；删去互相冲突的构图要求。先大字再小图、先图再文都可以，不固定颜色或无字规则。

## 三层验证，不能互相冒充

| 层级 | 做法 | 可以得出的结论 |
| --- | --- | --- |
| 设计预检 | 检查原图、实际尺寸消息卡、宽幅与方形裁切 | 内容关联、文字正确、是否可读；不是点击提升 |
| 目标读者模拟 | 在模拟信息流中随机展示候选，记录选择与内容预期 | 受试样本中的偏好和误解线索；不是平台真实CTR |
| 线上随机实验 | 同期随机分配受众，使用真实曝光与打开记录 | 条件满足时估计本次人群/入口的点击变化 |

没有受众或平台能力时完成可做的设计预检，交付实验方案并标未执行。LLM评审、视觉注意力预测、热力图和设计打分只能诊断，不能当真实用户或点击数据；多个代理投票也不是受众实验。

### 设计预检

把封面放进包含真实标题长度的消息卡，按拟发布入口的实际尺寸看；没有入口截图时明确说明模拟尺寸。检查文字、主题身份、主焦点和裁切完整性。只看大图不能宣布小图通过。
可做几秒钟的短时辨认检查，但“几秒”是操作约定，不是经验证的统一阈值。没展示给真人就只能称编辑自查。

### 目标读者模拟

- 招募符合目标读者的人，记录如何招募；亲友便利样本的偏差要披露。不设“找10个人就能证明”的通用数量。
- 每人随机只看一个版本，放入相同的其他文章卡片之间；卡片位置在两组平衡或随机，避免固定首位优势。
- 允许“都不打开”，不要强迫二选一，不先解释设计意图，不问“新版是不是更好”。
- 先记录是否选择目标文章，再问“你以为会讲什么”“为什么打开/跳过”。事后比较两图的偏好另记，不能混入首次选择率。
- 模拟选择率=选择目标文章人数/看到该版本的人数。报告原始人数和来源，不叫平台打开率。小样本用来发现误读，不用细小百分比差评冠军。

### 线上随机实验

先核实当前平台是否支持所需分流与数据，不能把YouTube的功能当成公众号已有功能。优先平台原生、可确认同期随机的实验。若无此能力，模拟测试或历史观察即可，不为测试擅自发重复文章或投广告。

实验开始前填写下方记录：
- **测试对象**：只测封面时标题、摘要、正文、入口、位置和分发条件保持一致。若改标题与封面，结论是组合效果；整张封面换概念可测试，但不能归因到某一种颜色或字体。
- **分配**：同期随机，尽量按用户稳定分组，同一人始终看同一版本；记录实际随机化单位及重复曝光处理。不要把上午A、下午B当随机A/B。
- **指标**：事先选择一个主指标，固定观察窗口；检查分流比例、曝光缺失、异常流量与跨组污染。数据口径不匹配先修数据，不宣布胜出。
- **样本与停止规则**：依据基线打开率、最小有意义差异、统计方法、显著性水平与检验功效规划。基线未知先做估计；没有通用“100人/三天必出结果”。达到预设窗口与样本目标后分析；不要看到领先就提前停。若用序贯方法，事先选定并遵循相应停止规则。
- **阅读质量**：选择实际可测的有效阅读、停留、误导反馈等辅助指标，预设不能接受的下降。不要假定后台提供完读率或所有需要的指标。

## 指标与解释

用户级打开率=窗口内至少打开一次的曝光用户数/看到该版本的独立用户数。事件级CTR=点击次数/曝光次数；两者不能混用。重复事件不能被当成互相独立用户用于统计。若只有送达人数，指标叫“按送达计算的打开率”，说明未证明实际看见封面。

示例为算术演示，不是真实测试：A为100/1000=10%，B为120/1000=12%。差异是+2个百分点，相对提升20%；仅有这组描述数字还不能直接宣称B获胜。

分析应报告样本、分子分母、绝对差、相对差（基线为0时不可计算）和匹配设计的差异置信区间或平台检验结果。不要用两个单组区间是否重叠代替差异检验。多版本、多次挑选或多指标择优要处理多重比较；探索得到的赢家可再用新样本确认。

在数据有效、事先确定的证据标准达到、收益有实际意义且质量指标无不可接受下降时，才能写“本次实验支持B更好”。否则用“方向性信号”“差异不明确”“数据不足”或“实验无效”，不把未显著误写成效果相等。

比较跨日期或不同文章的阅读量属于观察数据，可能受选题、受众、时段、推荐分发影响；不能据此隔离封面因果效果。不要把一次胜出固化成所有文章的风格规则。

## 可复制的记录模板

在文章目录review.md记录；确实运行实验时可单列cover-experiment.md：

- 状态：planned / running / completed / inconclusive / invalid（未跑就planned）
- 文章与读者、展示入口：
- A/B文件与对应标题、版本标识：
- 假设及唯一主要比较对象：
- 固定条件、随机化单位、分配比例与重复曝光规则：
- 主指标定义、原始计数字段、观察窗口：
- 阅读质量指标及不可接受下降：
- 基线、最小有意义差异、样本规划方法、停止规则：
- 原始数据来源与日期、缺失/异常/分流检查：
- A分子/分母；B分子/分母；差异与不确定性：
- 实际观察到的内容误解：
- 结论等级、适用范围、下一步：
- 未执行的环节：

只记已有证据；不填虚构数字、用户评价或统计结论。提议实验不等于获准联系读者、发布或付费。

## 来源与适用范围

核对日期：2026-09-30。上述封面构思是本skill的设计启发，不是来源证明的点击公式。实验部分结合下列一手资料，迁移到公众号时仍需验证入口与指标：
- [YouTube官方：A/B测试标题与缩略图](https://support.google.com/youtube/answer/16391400?hl=en)：区分同期与顺序测试，结果可不明确，并用观看时间而非只看点击。这里借鉴“点击后质量”原则，不把视频指标搬成公众号指标。
- [Microsoft Research：实验前的可信实验设计](https://www.microsoft.com/en-us/research/articles/patterns-of-trustworthy-experimentation-pre-experiment-stage/)：预先明确假设、指标与随机化，关注质量和偏差。
- [Microsoft Learn：实验最佳实践](https://learn.microsoft.com/en-us/xbox/playfab/live-service-management/game-configuration/experiments/experimentation-keys)：样本与统计可靠性影响决策，短期波动不能直接解释为效果。
